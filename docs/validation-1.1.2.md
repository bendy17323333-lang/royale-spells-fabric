# 1.1.2 验证记录

验证日期：2026-09-05。

## 机制检查

30 项 Minecraft 服务端 GameTest 全部通过，涵盖法术、召唤物、镜像、地震破坏预算、小屋出兵及保存重载。

新增火箭回归将模型头部方向与实际插值轨迹比较，覆盖普通／派对火箭，斜向、高低差和垂直施放，以及上升、顶点、下降阶段；检查尾焰位于尾部、旋转不出现无效数值。

## 实际游戏检查

- 独立 Fabric 客户端与现有整合包模组副本均进入新测试世界。
- 检查野蛮人正面、侧面、静止握剑和真实挥剑，以及原版骷髅和野蛮人小屋。
- 检查火箭三个飞行阶段，实际飞行的派对火箭完成上升和下降。
- Minecraft 解码器成功解码全部 15 个原版野蛮人 OGG。脚步播放池仅使用 `barb_footstep_03_no_vo`，播放音量不超过 0.12。独立行走场景记录到 4 次脚步，整合包场景记录到 5 次，两者均无攻击语音事件。
- 检查克隆、狂暴、冻结、藤蔓、墓园音效、Zap 与地震。
- 两个法术范围穿过玩家颈部时，范围绘制前后的 4096 个 GPU 深度采样值一致；保留第三人称前后视角检查。
- 核对 29 张原版卡图、29 项配方、29 个物品模型、3 个自定义实体模型。卡图与原版音频 SHA-256 与来源记录一致。

整合包测试使用 Java 17.0.8、Fabric Loader 0.19.3、Fabric API 0.92.11，以及 Liquid Glass UI 4.1.2、Sodium 0.5.13、Iris 1.7.6 等模组。未启用第三方光影包，未逐项验证其它模组的全部功能或远程多人环境。
