# 女巫与觉醒女巫 · 1.9.0 技术说明

这是 1.9.0 历史实现记录。1.9.1 的 Blockbench 原生模型、128×128 图集、0.72 格/tick 弹速与连续渲染时间轴见 [1.9.1 技术增量](WITCH-1.9.1.md)；本页旧美术描述与测试结果不可当作新版本验收。

目标环境：Minecraft 1.20.1、Fabric、Java 17。本轮在独立卡牌分支增加女巫与觉醒女巫，不重新引入铁魔法、卷轴、法杖或 MineClash 运行时依赖。女巫的独立法杖是模型组成部分，不是玩家可以持有的新武器。

## 使用、获取与费用

两张卡都花费 **5 圣水**。卡牌可重复使用；镜像正常复制上一次成功部署的女巫，花费 **6 圣水**并使用 12 级表。创造模式不扣圣水。两张卡拥有单独 ID 和独立配方，不要求先循环两次普通卡：这是本模组原有独立觉醒卡体系的延续。

工作台无形状配方：

| 卡牌 | 材料 |
|---|---|
| 女巫 | 纸 + 骨头 + 紫水晶碎片 + 发酵蛛眼 |
| 觉醒女巫 | 女巫卡 + 2 个紫水晶碎片 + 不死图腾 |

管理员命令：

```mcfunction
/royalespells give witch
/royalespells give witch_evolution
/royalespells refill
/royalespells clear
```

创造栏会显示这两张卡。`give` 不写卡名时会给全部卡。`clear` 只清理当前玩家拥有的召唤物和法术，不清除世界中其他玩家的单位。新配方的去重检查与原有 35 张卡一起执行。

## 服务器实体与攻击流程

`entity/RoyalWitch.java` 是 `PathfinderMob`，实现本模组 `Summoned` 接口。

- `ownerId()` 直接保存玩家 UUID。子骷髅继承同一玩家归属，避免玩家 → 女巫 → 骷髅多层引用让友军判断失效。
- `SummonOrders` 维持“玩家明确攻击目标优先，其次邻近敌对目标”的规则。未被玩家攻击、没有敌意的和平与中立生物不会被女巫主动选择。
- 远程 AI 追到射程内再站定施法，使用真实视线检测；不是每隔若干 tick 对准星下的对象直接扣血。
- `attackAge` 从 1 到 22 循环，在第 14 个有效动作 tick 释放一次法球。丢失目标/射程/视线会停止这次动作；再次进入范围会重新前摇。
- 电击、冰冻和眩晕只暂停当前攻击与召唤计时，不把已进行的前摇清零。雪球将动作、攻击计时与召唤计时推进速度降到 65%；狂暴按原有 1.35 倍推进。
- 服务端 `muzzle()` 与客户端模型释放姿势逐矩阵标定：距脚底约 1.675 格、向前 1.08 格、右侧 .34 格。法球从实际杖头释放。身体到杖头之间也有墙体检测，防止伸出的杖头穿墙后在墙另一侧生成法球。

`entity/WitchBolt.java` 是独立同步实体，`kind == 0` 为攻击法球。

1. 释放时保存女巫 UUID、玩家 UUID、目标 UUID、当次伤害和普通/觉醒外观状态。一次法球的伤害不会因稍后镜像或其它女巫属性变化而被串改。
2. 每个服务端 tick 追踪仍存活目标，前进 .6 格，对起点到终点做方块射线和膨胀实体碰撞箱的连续相交检测。
3. 选择最近的真实碰撞点；高速飞行也不跳过薄墙或狭窄生物。
4. 命中时只执行一次溅射。友军、施法者、创造玩家、被服务器禁止的 PvP 对象被排除；目标与撞击点之间有墙时不穿墙造成范围伤害。
5. 通过 `CombatImpact.withoutKnockback` 禁止附带击退；临时绕过受伤间隔，再恢复已有无敌时间，避免影响无关的其它攻击。
6. 命中后实体在原地保留 16 tick，供客户端三维雾气展开、流动与消散使用，期间不重复伤害。

客户端读取 `impactPosition()`、`impactNormal()` 和 `impactAge()`。撞击点和命中标记走同一份实体元数据，避免位置更新包略晚导致爆裂先出现在上一帧飞行位置。

## 首波骷髅与真实灵魂治疗

2026 年 8 月后的觉醒效果只登记自己**首波**实际生成的四只非克隆骷髅。后续召唤、其他女巫的骷髅、墓园、军团、复制骷髅都不能补充这四个名额。

每次召唤在女巫前后左右选四个独立落点，再进行地面、世界边界、已加载区块和碰撞检查。不能生成的位置不会暗中刷到墙里。沿用每玩家 64、世界 256 个召唤物的安全限制。狭窄位置或上限导致首波少于四只时，不会通过后续波次无限补充回血资格。

首波母体维护 `Set<UUID> firstWave`；对应骷髅保存 `RoyaleWitchMother`。骷髅真实死亡触发 Fabric `AFTER_DEATH`：

1. 事件确认它是本模组骷髅、已死亡、非克隆，母体还在同一世界且存活。
2. 母体同时检查归属相同、UUID 位于自己首波集合、尚未创建返回灵魂。
3. 母体为该骷髅生成唯一 `WitchBolt(kind=1)`，登记骷髅 UUID → 灵魂 UUID。重复死亡回调不会生成第二个灵魂。
4. 灵魂从死亡位置出发，20 tick 沿弧线飞向不断更新的女巫位置。到达之前不会加血。
5. 到达时，母体检查真实灵魂实体仍在场，类型、年龄、目标、源骷髅及位置全部相符，并检查唯一待处理 UUID；通过后原子消费该资格并加血。
6. 母体已死不会复活；实体暂未加载时灵魂可等待至多 200 tick，之后消散，不强制加载区块。

治疗可以超出初始最大生命。Minecraft 的 `setHealth` 会限制到 `MAX_HEALTH`，所以代码仅在治疗真实溢出时把最大生命提高到已获得的数值，最高是 1451/27 或 1593/27。刚部署时不会故意用半满生命条表示“满血女巫”。受到伤害后再收到灵魂，先正常恢复损失；四次灵魂不保证被伤害过的女巫仍能达到理论最高血量。

母体 NBT 同时保存首波集合、已生成但未抵达的灵魂映射、已收到的数量、召唤计时、部署计时、动作进度、普通/觉醒和等级。法球/灵魂保存原点、方向、碰撞状态、年龄、母体与骷髅 UUID。卸载重载不会凭空重新发放首波名额。删除、自然过期或普通 `discard` 不是死亡，不发放灵魂。

## 克隆、镜像与其他边界

- 克隆保留普通/觉醒身份和模型，生命上限 1；不会被误转成野蛮人。
- 克隆女巫后续生成的骷髅也是 1 生命克隆，无法产生回血灵魂。
- 不能再次克隆已经克隆的女巫。
- 镜像使用独立的新母体 UUID、独立首波资格和真实 12 级骷髅；两名女巫不会吃到同一只骷髅的灵魂。
- 普通与觉醒单位都沿用 Minecraft 玩家/队伍/驯服归属规则，不自带全地图阵营仇恨。
- 本模组所有召唤物都有有限存在时间；女巫 1800 tick（正常 20 TPS 下 90 秒），其骷髅不超过母体剩余时间或 1200 tick。这是 Minecraft 常驻世界的防积累规则，不声称是原作竞技场寿命。

## 渲染契约

`RoyalWitch` 只读同步接口：

| 方法 | 意义 |
|---|---|
| `evolved()` / `isClone()` / `cardLevel()` | 版本、克隆和等级 |
| `attackAge()` | 0 待机，1..22 攻击循环，第 14 tick 发射 |
| `attackProgress(partial)` | 攻击周期归一化进度 |
| `castProgress(partial)` | 前摇到释放的归一化进度 |
| `summonAge()` | 0 无动作，1..24 召唤动作 |
| `healFlash()` | 治疗到达后 10..0 闪烁剩余时间 |
| `muzzle()` | 与模型释放帧对齐的杖头世界坐标 |

`WitchBolt` 提供 `kind/evolved/age/impacted/impactAge/impactRadius/impactPosition/impactNormal/flightDirection/start`。客户端世界空间渲染器只显示服务端实际事件，不做目标选择或伤害结算。姿势状态按实体实例区分，避免一只女巫攻击时其他女巫也继承该姿势。

攻击体采用沿视线积分的三维密度场：集中粉紫亮芯、相连的暗紫外雾、跟随实际历史轨迹的尾雾，以及命中后的展开和密度衰减。它不是实体圆泡、交叉平面、面向摄像机的贴图或全屏滤镜。场景深度将雾体截在实际生物和地形之前，雾体本身不写深度。治疗灵魂有独立飞行和到达表现。

具体坐标、渲染阶段、深度拷贝、密度/颜色积分、状态恢复与性能预算见 [体积渲染技术说明](WITCH-VOLUME-RENDERING.md)。角色几何与材质单独工作，关闭 Bloom 并不会移除它们的结构；最终视觉仍须以真实游戏观察为准。

## 已执行的服务端测试

新增 `test/WitchTests.java` 八项 GameTest，与原有 37 项一起运行。第一次完整执行结果：**45 项全部通过**，见项目根目录 `witch-gametest.log`。最终打包前的再次验证以 `BUILD_STATUS.md` 记录为准。

1. 真实弹体产生 135/27 伤害，1.49 格内受伤、1.51 格外不受伤；友軍安全、无击退、无敌时间保留、持续爆裂不重复扣血。
2. 弹体必须经过飞行才命中；地形阻挡，爆点固定在墙面。
3. 20 tick 首波四只，之后 140 tick 四只；等级和归属正确。
4. 首波四只分别产生唯一灵魂；死亡瞬间和 19 tick 飞行阶段均不治疗；20 tick 到达才治疗并支持真实超量生命；拒绝重复、伪造与后续波次。
5. 母体和飞行灵魂 NBT 保留资格、已飞时间和归属；死亡母体不能复活。
6. 电击与冰冻暂停已进行的前摇及召唤计时，雪球减速，恢复后准确发射一次。
7. 克隆保持类型、等级和 1 生命，克隆骷髅也为 1 生命且不会治疗。
8. 实际卡牌路径扣除 5/6 圣水，镜像生成 12 级觉醒女巫，和平单位筛选与玩家攻击优先正确。

这组测试证明服务端行为；不能代替模型、材质、透明混合、帧间动画及与用户整合包的实机观察。客户端截图验证由独立渲染流程执行，未验证的模组包/光影/多人组合不会写成已通过。
