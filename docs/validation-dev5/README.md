## 录像与检查边界

视频为 1280×800、30 fps 输出，长度约 46.5 秒；来源是实际帧缓冲导出的 861 张带时间戳帧。按真实时间补帧，不改变游戏播放速度。原音效事件 46 个，全部按游戏实际选择的样本、音高、音量和距离混音；不是麦克风或声卡录音。字幕已检查，`video-snowball.png` 和 `video-fireball.png` 由最终 MP4 解码。

录制目标使用较高生命上限，便于一镜展示多次效果。没有对真实法术加伤害或延长状态。单机完整客户端证明这些展示场景，不等于覆盖所有第三方模型、多人网络条件、光影或显卡性能。

完整客户端日志还包含其它模组的已存在资源警告，例如液态玻璃梯子和铁魔法的一项模型引用。本轮没有跨项目修复它们，录像流程正常结束，没有本次皇室法术的渲染崩溃。

## 修复测试夹具的原因

旧精确魔力测试在同一服务器 tick 内多次调用回蓝管理器；旧测试场景也有实际尺寸超出 8 格模板边界的问题。修正测试玩家回蓝属性、扩大模板边界并将整个雪球起点放进场地后，完整回归通过。伤害、位移、时长和攻击恢复断言保留。最后一次修复前的失败 XML 和原 8 格模板保留，便于复查，没有把失败当成通过。
