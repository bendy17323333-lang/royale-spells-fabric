# 1.2.0 验证记录

2026-09-05，在 Windows、Minecraft 1.20.1、Java 17 和 NVIDIA RTX 4070 Laptop GPU 上完成以下检查。

- **36 项 Minecraft 服务端 GameTest 全部通过。** 新增实际半径边界、地震三轮累积与裂纹到期／续接、录制地图隔离、关闭 AI 的目标被普通雪球击退和被飓风拉动、墙体阻挡及小屋固定位置等检查。原有觉醒雪球裹挟释放、两段小电、镜像强化、墓园、克隆、小屋出兵、火箭弹道等检查继续通过。
- **开发客户端生成并保存了标准 1.20.1 超平坦地图。** 26 个场景逐一实际右键施法，验证前后切换、首尾循环、潜行重置和控制物品。地图存档标记为已完成、第 1 场；包含标准的三个原版维度，不依赖其它模组的维度数据。读取 NBT 检查 DataVersion 3465、第 1 格小电、第 8 格羽毛、第 9 格烈焰棒及区域文件。
- **正式 JAR 在用户当前全部模组的隔离副本中运行。** 使用 Fabric Loader 0.19.3、Fabric API 0.92.11、Sodium 0.5.13、Iris 1.7.6，以及实例中其余模组。26 场再次通过：普通雪球实际移动了 3 个关闭 AI 的目标，飓风移动了 8 个。这里的数字是该场景检测到的目标数，并非伤害上限。
- **检查实际游戏截图。** 小电短落雷与分叉有连续帧变化，地震第二轮木材仍在并有裂纹，第三轮木材碎裂；核对野蛮人正面／侧面握剑和木桶头皇家卫队。野蛮人沿用已确认的 1.1.2 面部几何。
- **整合包客户端回归检查通过。** 范围平面绘制前后 4096 个 GPU 深度值保持一致；第一／第三人称、克隆与狂暴着色、真实挥剑、原版骷髅、小屋和火箭完整升降阶段继续完成。独立行走场景记录 5 次脚步、0 次攻击语音，脚步最大音量 0.12。
- **素材与交付校验。** 安装包脚本核对 29 张原版卡图、29 项配方、31 个物品模型（新增两个场景控制物品）、3 个保留的自定义单位模型，以及墓园和 15 条野蛮人原音频的 SHA-256。发布 JAR 必须与上述两次正式客户端测试所用文件完全相同。地图包、源码包、安装包均通过 Windows `Expand-Archive` 解压检查。

测试使用新世界，没有打开或修改用户原有存档。正式客户端没有启用第三方光影包；未逐项验证所有第三方模组功能或远程多人环境。地图控制面向单人录制，多人共享当前场景。地震的短暂破坏进度用于后续地震累积，不改变工具挖掘速度，也不跨世界关闭保存。

实际日志、GameTest XML 和游戏截图随安装包提供。可分别使用 `runGametest`、`runVisualSmoke`、`runShowcase` 复现服务端、视觉及地图检查；只有显式启动测试任务才会运行自动流程。
