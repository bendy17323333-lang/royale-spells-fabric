# 1.9.1 Fabric 1.20.1 验证记录

本轮重做普通女巫与觉醒女巫原生模型，修正比例、面部、握杖和法球连续呈现。旧记录保留于 `docs/validation/BUILD_STATUS-1.9.0.md`，不作为本版验收证据。

## 模型与当前需求

在实际 Blockbench 5.2.2 / MCP 插件 1.10.0 桌面项目中编辑，并保存原生 `.bbmodel`。普通女巫 17 骨骼、91 网格、1100 面；觉醒女巫 18 骨骼、109 网格、1259 面；两者共用内嵌 128×128 像素图集。运行模型由原生源导出，面绕序、UV、骨骼旋转单位与材质哈希经过检查。

保留平顶兜帽，缩短躯干及面部开口，调整头宽、肩宽和袍摆。按最新反馈取消所有独立手指/拇指，使用整体块状手掌。普通版恢复羊头骨、分节弯角法杖，觉醒版保持其独立造型。旧 ImageGen 面部渲染层已移除。

两个原生项目共八张正面、侧面、背面和四分之三截图，路径、制作记录与哈希见 `art/witch-remake/model-provenance.json`。这些是编辑器截图，不冒充游戏截图。

## 正式 JAR 实际游戏检查

Java 17、Minecraft 1.20.1、Fabric Loader 0.16.14、Fabric API 0.92.6+1.20.1；隔离实例 mods 只有当前模组与 Fabric API。1280×800、Fancy、无外部光影或 Bloom。新建世界 `Witch-1.9.1-QA-remake-1791690996523` 正常运行、保存并退出。

- 实际 GPU 加载并绘制三维密度雾着色器。
- 62 张真实 framebuffer 截图全部完成，4483 个世界渲染帧；包含五机位攻击阶段、角色视角、近脸、侧面握持、自然寻路步态、召唤、归魂、减速和单体冻结。
- 1981 个实际 GPU 提交样本，47 个飞行主体、672 对有效飞行帧、930 对有效命中帧。
- 飞行静止帧比例 18.90%；未检测到定义范围内的静止后跳变、速度尖峰、时钟倒退或命中时间轴不连续。
- 188 个末段补程样本仍参加检查；最大原始命中差距 1.744 格，最大实际可见阶段切换帧差 0.630 格。首轮未补程的最大可见切换差距为 1.811 格；两次运行是不同采样，不能当作严格性能对照。
- 106 个长帧/非相邻帧间隙单独记录，未假称不存在。补程最多两 tick，不消除 GPU/调度停顿；也会略过最前约 0–2 tick 的爆发表现。
- 雪球动作减速/恢复、单体冻结/恢复及另一女巫持续动作的隔离检查通过。

直接查看最终 20 张实机截图，逐图观察与哈希保留于 `docs/validation/witch-visual-review.json`。62 是采集数量，不代表逐张人工审美通过。查看画面中，手掌没有独立手指或尖刺，握杖位置稳定，前后轮廓与衣料分层可辨；法球具有亮粉紫中心/暗紫外围雾，石柱会遮住雾体中心，消散后背景逐渐恢复可见。脸部表情仍偏冷峻，雾仍偏柔软；这些具体画面供用户判断，不声明用户已经认可，也不把编译/采集通过称为专业美术验收。

## 性能及验证边界

4392 个帧间隔样本：均值 19.87 ms、P50 17.14 ms、P95 37.22 ms、最大 242.58 ms；60 FPS 上限，包含截图读回。不是用户整合包性能承诺或弱网测试。体积渲染继续使用距离步数、最近 40 个效果和采样预算，未验证大规模战斗、多人、Iris/Sodium/Fabulous 全组合及旧世界完整迁移。

离线 QA 用户的认证 401，以及明确列出的 13 个本模组实体 DataFixer 注册提示被保留并单独识别；没有一概忽略 ERROR。未见本轮 shader 编译/链接、mixin 应用或资源加载失败。
