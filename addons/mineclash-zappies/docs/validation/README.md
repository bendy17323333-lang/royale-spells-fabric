## 录像方式

`BattleShowcase` 在独立新世界布置场地，生成原生皮卡 / 皇室法术飞龙与三辆电击车，赋予双方敌对目标；不篡改生命、伤害、命中、控制时间或战斗结果。皮卡采用本体默认属性，电击车按附属默认 11 级，飞龙按基础召唤属性。死亡后保留五秒用于观察，不拼接伪造胜负。

画面由 `Screenshot.takeScreenshot` 读取游戏自己的帧缓冲，后台写 PNG 并保存实际时间戳，之后编码为 MP4。掉帧时保留真实时间，不把缺失画面误当成加速战斗。最终文件编码为 30 fps，不宣称每秒都捕获了 30 个不同游戏帧。

本机系统回放录音返回静音，因此使用 **事件音轨**：`SoundEventListener` 记录本场实际解析出的原音频样本、随机样本选择、触发时间、音高、距离衰减和循环停止点。`tools/encode-battle.py` 同步混音并轻微降低总音量；没有使用麦克风或混入其它应用声音。这是依据真实事件的音频重建，不是系统声卡录音。

原始素材仍属于对应原作者。录像中的 MineClash 模型、动画、声音出处见 [项目首页](../../README.md)。原始依赖 JAR、反编译研究、整合包存档、音频拆出文件均不放进附属源码包。

## 可复现工具

- `tools/launch-client.py combat pack<唯一后缀>`：独立整合包客户端检查。
- `tools/verify-client.py <运行目录>`：核对实际骨骼、时间、独立开火与死亡后姿势。
- `tools/launch-client.py battle packpekka<唯一后缀>` / `packdragon<唯一后缀>`：新世界对战录制。
- `tools/encode-battle.py <运行目录>`：从真实导出帧与事件音频产生视频。

启动器是本工作区的 QA 工具，依赖外部已经准备好的合法 Minecraft 运行库。没有把玩家账号凭据、依赖 JAR 或完整游戏打包进交付。用户自己的 CurseForge 实例及原存档未替换、未修改；远程多人延迟和其它未知模组特殊动作仍需后续实测。
