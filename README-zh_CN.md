## 安装与使用

1. 在启动器中选择 Minecraft 1.20.1，安装 Fabric Loader 0.16.14 或兼容的新版本。
2. 将 `royale-spells-fabric-1.20.1-1.2.0.jar` 放入该游戏实例的 `mods` 文件夹，并安装对应 1.20.1 的 Fabric API。本项目验证使用 Fabric API 0.92.6+1.20.1。安装包内已附带该依赖；若实例中已有兼容的 Fabric API，请保留一份，避免重复安装。
3. Java 17 或以上；联机时服务端和每位玩家的客户端都需要本模组与 Fabric API。
4. 创造模式在“皇室卡牌”物品组取卡；生存模式使用下表的无序配方。
5. 手持卡牌时显示瞄准圈，**右键施法**，瞄准距离最多 32 格。卡牌不消耗，可以重复使用。
6. 圣水上限 10，每两秒恢复 1 点。每次施法有半秒公共间隔；创造模式免圣水消耗。手持卡牌时快捷栏上方显示圣水。

管理员／开启作弊时可使用：

```mcfunction
/royalespells give
/royalespells give zap_evolution
/royalespells refill
/royalespells clear
```

`give` 不带参数时给自己全部 29 张卡；`refill` 补满自己的圣水；`clear` 清理自己在当前维度的法术效果和召唤物。

## 召唤物

- **小僵尸**：原版幼年僵尸外观，持木剑，最大生命值 10；假桶小僵尸最大生命值 3、攻击较弱。
- **墓园骷髅**：原版骷髅外观，持石剑近战，普通墓园召唤物最大生命值为 **6**，低于原版骷髅的 20。存档重载后仍保留血量上限、武器和归属。
- **野蛮人**：定制方块人形模型，金发、胡须和铁剑，最大生命值 20。
- **皇家卫兵**：木桶头盔、蓝色羽毛、灰钢胸甲，外观为木盾、长矛和初始吸收护盾，最大生命值 24。
- 骷髅存活 20 秒，其余普通召唤物存活 30 秒；克隆体存活 20 秒。召唤物不掉装备、战利品或经验，也不拾取物品。
- 每位施法者在一个维度中最多保有 64 个召唤物；单个维度最多 256 个召唤物和 256 个法术效果。
- 召唤物自动寻找附近敌人，无敌人时靠近主人；不会攻击自己的主人、同归属召唤物及记分板队友。

## Minecraft 适配规则

- 物品图标直接使用皇室战争原版卡图。小僵尸卡牌仍保留原哥布林卡图，以遵循“原版卡图”要求。
- 雷电使用 Minecraft 自带闪电外观，但通过单独的伤害机制控制选敌，不额外点燃地面或触发生物闪电转化。
- 地震按三次震荡累积破坏：第三次破坏范围内木材和树叶，石材保留 90% 进度约 5 秒，可由后续地震继续破坏。其它法术保留地形；附带的演示竞技场单独放在录制地图中。
- 觉醒通过独立卡牌直接施放，每次都是觉醒效果；不引入原游戏的卡组槽位及轮转解锁系统。Zap 使用重做后的双击版本。
- 克隆覆盖本模组的己方召唤物，不复制玩家或第三方模组生物。克隆体不能再次被克隆。
- 原版中立动物也可成为敌方目标；自己的驯服生物、召唤物和记分板队友属于友军。多人敌我关系可使用原版 `/team` 配置。
- 圣水和上次使用卡牌为当前在线会话状态，重新加入游戏后重置；实体归属、剩余寿命、飞行目标和法术进度会写入实体存档。

## 构建与验证

解压源码工程，构建建议使用已验证的 JDK 21。在工程目录运行：

```powershell
./gradlew.bat build
./gradlew.bat runGametest
./gradlew.bat runVisualSmoke
```

第三个任务会在工程自己的 `run-visual` 目录创建隔离测试世界、展示模型并截图，完成后自动关闭开发客户端。它不会打开或编辑你的正式游戏存档。正式游戏不会启用该开发流程。

`build/libs` 中无 `sources` 后缀的 JAR 才是安装文件。源码 ZIP 包含完整 Gradle wrapper、Java 源码、原版卡图、生成粒子贴图和资源文件。

素材来源和 imagegen 提示词见 `ASSETS.md`，每张原版卡图的下载地址及 SHA-256 见 `ASSET-SOURCES.json`。验证结果见随交付文件提供的 `验证报告.md`。



## 1.0.1 墓园原版登场音效

墓园现在会在施放位置播放皇室战争的经典登场音效，每次施法播放一次，保持原速原调。使用原始单声道 OGG，未剪辑或重新编码，约 3.07 秒；附近玩家可听见，按距离衰减，最远约 32 格。音量由游戏的“玩家”音量选项控制，开启字幕后显示“墓园：亡灵登场”。墓园仍召唤拿石剑、最大生命值为 6 的骷髅。升级时删除旧版模组 JAR，只保留最新版。

## 1.0.2 滚木、虚空与地震更新

- 滚木：长轴横向摆放，绕长轴向前翻滚；转速随实际移动距离变化，外观跟随地面高度，原木端面沿正确轴向显示。
- 虚空：参考皇室战争的暗色圆形领域、红色边缘、亮色核心下落光束重建动态特效。三轮伤害分别在第 16、40、64 tick 触发，每名实际命中的敌人都有一道从上方劈落的光束；单目标光束更粗、更亮，多目标较细。特效与服务器命中快照同步，保留原有伤害数值。
- 地震：半径 3.5 格的圆柱内，从施法高度向下 3 格、向上 32 格，破坏木板、原木、树叶、木楼梯、木台阶、木门、木活板门、木栅栏、木栅栏门、告示牌、竹材、红树根及木制家具。石材、矿石、泥土不在破坏列表内。房屋或树木超出范围的部分会保留，不进行范围外的连锁砍伐。
- 地震分批处理，每 tick 最多检查 24 个候选方块，每次施法最多直接破坏 1024 个方块。正常掉落方块与容器内容物，遵循 doTileDrops；存档恢复不会重置破坏额度。施法玩家的原版出生点保护与 Fabric 方块破坏回调会被检查；第三方领地插件的兼容性取决于其是否接入对应事件。
- 数据包可修改 royalespells:earthquake_breakable 方块标签扩展破坏材质。

升级时删除旧版本的模组 JAR，只保留最新版。墓园原版登场音效继续保留。

## 1.0.3 视觉与机制重做

- 停用统一紫色星芒和所有法术共用的漂浮粒子圈。狂暴、毒药、冰冻、墓园等使用各自简洁的地面领域；火焰、烟、碎土、雪花仅用于对应法术。旧星芒资源仅为资源兼容保留，施法不再生成。
- 虚空改为红橙色外缘、橙色光束和暖黄亮芯，移除粉紫色偏色。
- Zap 使用细小蓝白色折线电弧从上方劈下，不生成真正的 Minecraft 闪电实体。觉醒第一击半径 2.5 格，第二击半径 3 格；伤害判定与显示范围一致。
- 狂暴影响的生物呈紫色染色；效果消退后恢复。
- 克隆体呈青色半透明外观，克隆状态实时同步客户端并写入存档；仍只有 1 点最大生命值，不能递归克隆。装备和附加渲染层仍使用各自材质，主体模型变为半透明。
- 冰冻生物增加蓝白染色、半透明冰壳和冰晶；仅冰冻法术出现冰壳，Zap 的眩晕不会冒充冰冻。
- 藤蔓在实际束缚目标身上生成立体螺旋藤条和叶刺模型，随目标位置移动，解除后消失。
- 火箭改为不齐的木板桶身、金属箍、补丁、木翼与外露炸药，使用 Minecraft 原版方块材质。
- 墓园骷髅每击基础伤害降至 **1.5 点（0.75 心）**；石剑保留为外观，不叠加原版石剑的攻击加成。每只骷髅自己的攻击仍遵循攻速，但多只骷髅同一 tick 命中可以分别造成伤害。只绕过这些骷髅的受伤间隔检查，原版护甲、盾牌、友军判断、玩家 PVP 开关和其它攻击的受伤间隔继续生效。
- 镜像复制上一张普通或觉醒法术，并按高一级给予伤害和治疗量 ×1.1、召唤物生命和攻击 ×1.1；额外消耗 1 圣水。持续时间、控制时长、射程及半径不因升级变化；克隆体生命仍为 1。连续镜像不会叠加等级，镜像不替换记忆的原卡。
- 原版模型之外的第三方生物渲染器、着色器以及其它渲染 Mixin 未逐一验证；开发客户端已经验证普通生物和本模组召唤物的染色、半透明、冻结与藤蔓表现。

替换旧版 JAR，只保留最新版。地震拆木屋／树木、滚木滚动与墓园原版音效继续保留。

- 火箭和派对火箭头部沿实际飞行轨迹转动：上升朝上，顶点转为水平，下落朝下。考虑落点高低差、斜向和垂直施放；尾焰和烟从实际尾部沿反方向喷出。弹道、飞行时间及伤害不变。
